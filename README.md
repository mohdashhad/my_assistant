# my_assistant
This project is a voice-activated desktop assistant built using Python. It listens to your voice commands and performs tasks like opening websites, telling the time, searching the web, launching applications, and more—making it a hands-free productivity tool.
Features
🎤 Speech Recognition: Listens to voice commands using a microphone

🔊 Text-to-Speech: Responds with spoken feedback using pyttsx3

🌐 Web Automation: Opens websites like Google, YouTube, or your favorite site

🕒 Time and Date: Tells you the current time or date

🔍 Wikipedia Search: Answers questions by reading Wikipedia summaries

📁 App Launcher: Opens local applications (like Notepad, Chrome, etc.)

🗣️ Custom Commands: Add your own phrases to perform new actions

🛠️ Technologies Used
Python 3.x

speech_recognition – to convert voice to text

pyttsx3 – for text-to-speech conversion

wikipedia – to fetch data from Wikipedia

webbrowser – to open URLs in the browser

datetime – to fetch current time/date

os – to access system-level operations
